### 配置 Docker 镜像源

```sh
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://dockerproxy.net",
    "https://proxy.vvvv.ee",
    "https://dockerproxy.link"
  ]
}
EOF
sudo systemctl daemon-reload
sudo systemctl restart docker
```

### containerd 配置

```sh
sudo tee /etc/containerd/config.toml <<EOF
[plugins."io.containerd.grpc.v1.cri".registry]
  [plugins."io.containerd.grpc.v1.cri".registry.mirrors]
    [plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
      endpoint = [
            "https://docker.1ms.run",
            "https://dockerproxy.net",
            "https://proxy.vvvv.ee",
            "https://dockerproxy.link"
      ]
EOF
sudo systemctl daemon-reload
sudo systemctl restart containerd
```

### 自建 Docker 镜像加速方案

* [cmliu/CF-Workers-docker.io](https://github.com/cmliu/CF-Workers-docker.io) - 基于 Cloudflare Workers 的 Docker 镜像代理
* [ciiii/cloudflare-docker-proxy](https://github.com/ciiiii/cloudflare-docker-proxy) - Docker Registry 代理运行于 Cloudflare Worker
* [dqzboy/Docker-Proxy](https://github.com/dqzboy/Docker-Proxy) - 一键部署 Docker、K8s、Quay、Ghcr、Mcr、Nvcr 镜像加速服务
* [NoCLin/LightMirrors](https://github.com/NoCLin/LightMirrors) - 开源缓存镜像站，支持 DockerHub、PyPI、PyTorch、NPM
* [brighill/registry-mirror](https://github.com/brighill/registry-mirror) - 自建简易 Docker 镜像加速&缓存（gcr.io、quay.io、nvcr.io、docker.io）
* [sky22333/hubproxy](https://github.com/sky22333/hubproxy) - 自托管轻量级多功能代理加速（Docker、GitHub、HF 模型）
