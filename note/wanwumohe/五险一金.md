# 五险一金

| 项目      | 缴费比例              | 作用                            | 特点             |
| ------- | ----------------- | ----------------------------- | -------------- |
| 1.养老保险  | 个人8%，单位20%        | 累计**交满15年**，退休后终身有养老金，        | 可以中断，影响不大      |
| 2.医疗保险  | 个人2%,单位10%        | 医疗保险50%以上，退休后享受医保             | **中断3个月**以上会失效 |
| 3.生育保险  | 个人0%，单位0.8%       | 生育后资料给单位，保险相关费用               | 个人不能交生育保险费     |
| 4.工伤保险  | 个人0%，单位0.2-1.4%   | 工作时受伤报销医疗费，保工作期间和上下班途中事故      | 个人不能交工伤保险费     |
| 5.失业保险  | 个人1%，单位2%         | 交满1年，失业后按缴纳年限领取失业保险金，主动辞职不能领取 | 个人不能交失业保险      |
| 6.住房公积金 | 个人5%-12%，单位5%-12% | 租房、买房、建房、装修都能用                | 住房公积金可以断交      |

## 失业保险 <a href="#title-1" id="title-1"></a>

1. 失业也有钱领，国家给的保障
2. 领取条件：\
   ① 非本人意愿的失业\
   ② 失业之前，所在单位累计缴纳的失业保险金也满1年
3. 重点\
   ① 每个月1000员左右，最多拿24个月\
   ② 失业金没有次数限制，符合条件就能领取。
4. 注意事项\
   失业后六十天内进行登记，进行生活费的领取

## 住房公积金 <a href="#title-2" id="title-2"></a>

### 公积金是什么? <a href="#title-3" id="title-3"></a>

* 五险一金里的"一金"
* 可以理解为国家开了专属账户,帮咱们村的是长期住房储蓄
* 一般按缴费基数的5-12%扣除，存进公积金账户中
* 是对等存缴！比如自己交1K,公司也得交1K,但是这最后2K都进入到自己的公积金账户里
* 自己交一份钱可以**领取两份**

### 公积金怎么用？ <a href="#title-4" id="title-4"></a>

* 买房：提取余额用来付首付/不提取用来贷款，利率低能省钱
* 建房：在农村建造/翻建住房使用了住房贷款，可以提取公积金\
  PS：提取的金额不能超过修建房的费用
* 租房：可以用公积金支付配租或者政府招租补贴的租赁房房租
* 父母给儿女买房：没有贷款过可以给孩子申请贷款
* 治疗重大疾病：家人患重病/住院手术，可以申请提取公积金\
  PS：得在出院后1年内申请，提取总金额不能超过自费医疗费总额
* 全部提取：退休、出国定居、身故等特殊情况

1. 买房贷款、租房、还贷、装修都能用
2. 重点：\
   ①公积金买房利率低，但是断缴不能申请\
   ② 公积金每年7月有年息\
   ③公积金贷款有上限，每个城市不同，所以账户余额多了也没用，记得领取
3. 率缴纳比率：\
   ①大部分是-公司和个人按照1:1的比例来缴\
   ② 很多公司会按照最低工资标准作为基数
4. 公积金的使用:\
   ①住房型：买房、租房、还贷、翻新、装修\
   ② 非住房：离职、大病、出国、退休、死亡

## 养老保险 <a href="#title-5" id="title-5"></a>

1. 简单点说，就是退休国家给咱发“工资”
2. 二领取条件：\
   ①女性55周岁男性60周岁；\
   ② 退休之前养老保险累计缴满15年
3. 重点：\
   ①不支持一次性补缴\
   ② 到了退休年龄缴费不满15年，可以再接着缴5年\
   ③个人可以交养老保险，但没有公司划算\
   ④缴费基数越高，缴费年限越长，退休可以连着领到的钱越多

## 医疗保险 <a href="#title-6" id="title-6"></a>

1. 累计年限\
   ①男性需缴满25年，女性20年\
   ② 缴满之后，即使不再缴费。也可以享受医保待遇
2. 重点\
   ①断缴少于3个月，补缴后次月才能再用\
   ② 断绝大于3个月，小于6个月，补缴之日起6个月后可以再用\
   ③断缴大于12个月，补缴之后1年可以再用\
   ④报销原则：两定点，三目录，起付线以上，封顶线以下，报销有比例和用药限制

## 生育保险 <a href="#title-7" id="title-7"></a>

1. 可以报销孕检、生育费，还能领生育津贴
2. 报销条件：\
   ①须在所在单位缴满1年\
   ② 在当地生育才能报销
3. 生育津贴：\
   ①领取额度为：上年度单位人均月缴费工资/30天X产假天数\
   ② 产假工资和生育津贴只能二选一，哪个高就领取哪个
4. tips：\
   ①男女都要缴纳\
   ② 没有工作的女性，可以用老公的生育保险报销\
   ③如果中断要连续缴纳一年才能享受

## 工商保险 <a href="#title-8" id="title-8"></a>

1. 因为工作导致的受伤、职业病都赔
2. 常见的工伤类型\
   ①职业病\
   ② 工作时间、工作场所、出差、上下班途中发生事故伤害等
3. 重点：\
   ①记得保存相关证据，不要用医保卡结算看病费；\
   ② 第一时间报警或跟HR报备
