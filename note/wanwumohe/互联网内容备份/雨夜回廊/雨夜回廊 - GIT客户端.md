* [desktop/desktop](https://github.com/desktop/desktop) | 官方 Git Desktop
* [zetaloop/desktop](https://github.com/zetaloop/desktop) | 汉化版
* [cngege/GitHubDesktop2Chinese](https://github.com/cngege/GitHubDesktop2Chinese) | 汉化补丁
* [robotze/GithubDesktopZhTool](https://github.com/robotze/GithubDesktopZhTool) | 汉化补丁
