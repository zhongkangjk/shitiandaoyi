# 视频下载工具

一些可以下载不同平台的视频的工具

## YouTube

* [YT-DL GUI Index](https://www.reddit.com/r/youtubedl/wiki/info-guis) - YouTube下载器图形用户界面列表
* [yt-dlp](https://github.com/yt-dlp/yt-dlp) - YouTube命令行下载器
  * [Commands](https://github.com/TheFrenchGhosty/TheFrenchGhostys-Ultimate-YouTube-DL-Scripts-Collection) - 命令集
  * [Discord](https://discord.gg/H5MNcFW63r) - Discord社区
* [cobalt](https://cobalt.tools) - 多站点/在线下载器
  * [Instances](https://instances.cobalt.best) - 实例
  * [Playlist Support](https://playlist.kwiatekmiki.pl), [Playlist Support 2](https://playlist.kwiatekmiki.com) - 播放列表支持
* [Videomass](https://jeanslack.github.io/Videomass) / [GitHub](https://github.com/jeanslack/Videomass) 或 [ezytdl](https://github.com/sylviiu/ezytdl), [Tartube](https://tartube.sourceforge.io), [Media Downloader](https://github.com/mhogomchungu/media-downloader) 或 [Parabolic](https://github.com/NickvisionApps/Parabolic) - 跨平台YT-DLP GUIs
* [yt-dlp-gui](https://github.com/kannagi0303/yt-dlp-gui) / [Easy Installer](https://github.com/kazukikasama/youtube-dlp-gui-installer), [ytdlp-interface](https://github.com/ErrorFlynn/ytdlp-interface), [dsymbol yt-dlp](https://github.com/dsymbol/yt-dlp-gui) 或 [Vividl](https://github.com/Bluegrams/Vividl) - YT-DLP GUIs
* [MeTube](https://github.com/alexta69/metube) 或 [yt-dlp Web UI](https://github.com/marcopeocchi/yt-dlp-web-ui) - 自托管YT-DLP WebUIs
* [Stacher](https://stacher.io) 或 [oleksis youtube-dl-gui](https://github.com/oleksis/youtube-dl-gui) 或 [StefanLobbenmeier youtube-dl-gui](https://github.com/StefanLobbenmeier/youtube-dl-gui) - 跨平台youtube-dl GUIs
* [Cube YouTube Downloader](https://github.com/database64128/youtube-dl-wpf) - youtube-dl GUI
* [YoutubeDL-Material](https://github.com/Tzahi12345/YoutubeDL-Material) - 自托管youtube-dl WebUI
* [YTDL-PATCHED](https://github.com/ytdl-patched/ytdl-patched) - YouTube命令行下载器 / yt-dlp分支
* [YoutubeDownloader](https://github.com/Tyrrrz/YoutubeDownloader) - YouTube下载器应用
* [ytarchive](https://github.com/Kethsar/ytarchive) - YouTube直播下载器
* [YouTube Thumbnail Grabber](https://boingboing.net/features/getthumbs), [YTI](https://youtubethumbnailimage.com), [thumbnailsave](https://thumbnailsave.com), [thumbnail-download](https://thumbnail-download.com) 或 [Get YT Thumbnail](https://www.get-youtube-thumbnail.com) - 下载视频缩略图
* [youtube-comment-downloader](https://github.com/egbertbouman/youtube-comment-downloader) - 下载YouTube评论
* [YT Subtitle Downloader](https://greasyfork.org/en/scripts/520194) - 下载视频字幕
