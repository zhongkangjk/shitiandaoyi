Crx搜搜：<https://www.crxsoso.com/webstore/detail/jfgfiigpkhlkbnfnbobbkinehhfdhndo>

## 运行环境与管理工具

#### LM Studio

Discover, download, and run local LLMs。支持在本地运行 Llama 3.2、Mistral、Phi、Gemma、DeepSeek、Qwen 2.5 等架构的模型，可聊天、使用本地文档、通过 Chat UI 或 OpenAI 兼容本地服务器使用模型，还能从 Hugging Face 仓库下载兼容模型文件，并在应用内发现新的 LLMs。支持在 M1/M2/M3/M4 Mac 或支持 AVX2 的 Windows/Linux PC 上运行，基于 llama.cpp 项目开发，个人使用免费，有团队招聘需求。

官网：<https://lmstudio.ai/>

#### AnythingLLM

Chat with your docs, use AI Agents, hyper-configurable, multi-user, & no frustrating set up required

官网：<https://anythingllm.com/>

Github：<https://github.com/Mintplex-Labs/anything-llm>

#### songquanpeng/one-api

OpenAI 接口管理与分发系统，支持 Azure、Anthropic Claude、Google PaLM 2 & Gemini、智谱 ChatGLM、百度文心一言、讯飞星火认知、阿里通义千问、360 智脑以及腾讯混元。可用于二次分发管理 key，仅需单个可执行文件，已打包好 Docker 镜像，一键部署，开箱即用。提供英文界面，使用单一 API 管理所有 LLMs。

Github：<https://github.com/songquanpeng/one-api>

#### Calcium-Ion/new-api

AI 模型接口管理与分发系统，基于 One API 二次开发。支持将多种大模型转为 OpenAI 格式调用，还支持 Midjourney Proxy、Suno、Rerank，兼容易支付协议，可用于个人或企业内部管理与分发渠道。具备全新 UI 界面（部分待更新）、多语言支持（待完善）、分页显示数量选择、兼容原版 One API 数据库、模型按次数收费、渠道加权随机、数据看板、设置令牌调用模型、Telegram 授权登录等功能，支持多种模型及自定义渠道。

Github：<https://github.com/Calcium-Ion/new-api>
