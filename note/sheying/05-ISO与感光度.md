# 第 5 课：ISO（感光度）——亮度、噪声与画质取舍

## 1. 需要了解的知识

### 1.1 ISO（感光度）是什么

摄影中的 ISO 是感光度标度的通用写法，中文通常称为**感光度**。它不是一串需要逐字翻译的摄影英文缩写。ISO 也是国际标准化组织的通用名称；该组织说明 ISO 名称源自希腊语 *isos*（相等），并非英文全称的首字母缩写。[ISO 对名称的说明](https://www.iso.org/about)。胶片时代，ISO 数值表示胶片对光的感光等级；数码相机中，提高 ISO 通常会放大传感器信号，并可能改变后续处理。提高 ISO 后，照片预览亮度通常变高，但传感器并没有因此收到更多光。

### 1.2 ISO 数值怎么理解

常见数值有 ISO 100、200、400、800、1600 等。ISO 每提高一倍，通常称为增加一档：

`ISO 100 → 200 → 400 → 800`

在快门和光圈不变时，提高 ISO 通常让照片输出亮一档；ISO 减半则通常暗一档。数码设备常有三分之一档等细分，也有扩展 ISO 设置。

```text
同一场景、快门与光圈不变：
ISO 100 → ISO 200 → ISO 400
输出亮度通常逐档提高，记录的光量没有增加
```

图 1：提高 ISO 改变信号输出，不等于增加镜头进光。

### 1.3 ISO 与噪声、细节

ISO 越高，画面越容易出现颗粒状亮度噪声或彩色斑点，暗部细节也可能不够干净。实际效果取决于传感器、曝光量、温度、降噪和输出尺寸，不同设备不能只凭 ISO 数字比较。

如果快门太慢会导致主体模糊，提高 ISO 换取更快快门，往往比得到一张清晰但拖影的照片更合适。噪声可以接受或后期处理，已经发生的运动模糊通常更难补救。

### 1.4 原生 ISO、扩展 ISO 与自动 ISO

设备通常有一个或多个表现较好的基础感光设置，常称**原生 ISO**或基础 ISO。具体定义和位置依设备而异。扩展 ISO 可能通过额外信号处理获得更亮或更暗的输出，不一定带来更多可记录细节。

**自动 ISO**让相机在用户设定的范围内自动调整 ISO。它常与光圈优先、快门优先或手动曝光搭配。应了解设备的最低/最高 ISO、最慢快门限制及自动 ISO 行为。

### 1.5 什么时候提高 ISO

- 主体运动，需要更快快门时。
- 手持拍摄，当前快门容易造成相机抖动时。
- 光圈已达到想要的景深或镜头限制时。
- 现场不适合补光，且不想接受欠曝时。

选择 ISO 时不是追求最低数字，而是让快门、光圈满足拍摄目的后，在可接受的画质范围内使用所需 ISO。

### 1.6 ISO 不能替代高反差场景的处理

提高 ISO 不会增加传感器收到的光，也不会让一次拍摄突然同时记住更多极亮和极暗的细节。若为了保护窗外或舞台灯光而让主体欠曝，再在后期大幅提亮阴影，噪声通常会更明显；这与拍摄时获得足够光量不同。

相机和手机有时会用多张不同明暗的照片来处理这种高反差场景。这个方法在第 10 课会以 HDR 的名称完整讲解；现在只需分清：提高 ISO、后期提亮阴影和多张照片合成，不是同一件事。
