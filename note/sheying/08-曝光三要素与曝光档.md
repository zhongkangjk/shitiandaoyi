# 第 8 课：曝光三要素与曝光档

## 1. 需要了解的知识

### 1.1 三要素分别控制什么

快门、光圈和 ISO 都会影响照片亮度，但各自还带来不同结果：

| 设置 | 主要控制 | 同时影响 |
|---|---|---|
| 快门时间 | 感光持续时间 | 运动凝固或拖影、相机抖动 |
| 光圈 | 镜头通光开口 | 景深、镜头成像表现 |
| ISO | 信号输出敏感度 | 噪声与细节表现 |

曝光不是只把照片调亮或调暗。拍摄者是在三种控制方式之间选择，既满足亮度，也尽量得到想要的运动、景深和画质。

### 1.2 什么是曝光档

一档（stop）代表光量或曝光量加倍/减半。完整一档的常见变化：

- 快门时间加倍：`1/250 → 1/125 秒`，进光约增加一档。
- 光圈开大一档：`f/4 → f/2.8`，进光约增加一档。
- ISO 提高一档：`ISO 100 → 200`，输出亮度通常增加一档，但进光不变。

注意：快门和光圈改变的是到达感光面的光量；ISO 改变的是信号输出。它们在曝光表上可以相互补偿亮度，但对画面的副作用不同。

### 1.3 等效曝光组合

如果把一个设置增加一档，再把另一个减一档，整体亮度可大致保持不变。例如：

```text
组合 A：1/250 秒 · f/4 · ISO 100
组合 B：1/500 秒 · f/2.8 · ISO 100
快门少一档进光，光圈多一档进光，整体亮度近似相同
```

两张照片亮度接近，但动作和景深可能不同。又如 ISO 提高一档、快门加快一档，也可让输出亮度近似不变，但高 ISO 的噪声表现可能变化。

### 1.4 先按画面目标，再安排曝光

选择顺序可以是：

1. 判断需要凝固动作还是允许拖影，据此选快门范围。
2. 判断需要浅景深还是较大清晰范围，据此选光圈。
3. 根据现场亮度和画质要求调整 ISO。
4. 检查整体亮度和高光细节，必要时重新取舍。

这不是每次都必须照抄的流程。例如，拍摄瞬间稍纵即逝时，先保证快门可能更重要；拍静物时，景深和三脚架条件可能更重要。
