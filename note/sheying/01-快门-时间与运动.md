# 第 1 篇：快门——用时间控制曝光与运动

## 1. 需要了解的知识

### 1.1 快门是什么

快门是控制感光过程持续时间的机制。按下快门后，影像传感器（或胶片）在一定时间内接收来自场景的光。这个时间叫**快门时间**或**曝光时间**。

可以把它想成给光线开一扇门：门开得久，感光面累积的光通常更多；门开得短，光通常更少。机械快门、电子快门和手机传感器读取方式的实现各有不同，但入门时先理解感光持续时间即可。

常见的快门时间写法：

- `1/1000 秒`：千分之一秒，时间很短。
- `1/125 秒`：比 `1/1000 秒`长，约长 8 倍。
- `1 秒`：曝光持续一秒。
- `30 秒`：曝光持续三十秒。

有些设备只显示 `1000`，通常表示 `1/1000 秒`；显示 `1"`通常表示一秒，具体以设备显示规则为准。

### 1.2 快门时间对曝光的影响

在光圈和 ISO 不变时，曝光时间加倍，感光面接收的光量约加倍；曝光时间减半，光量约减半。摄影常用“档”描述这种倍数关系：

| 快门变化 | 曝光变化 |
|---|---:|
| 1/1000 → 1/500 秒 | 增加 1 档，光量约加倍 |
| 1/500 → 1/250 秒 | 增加 1 档，光量约加倍 |
| 1/250 → 1/500 秒 | 减少 1 档，光量约减半 |

例如，`1/250 秒`比`1/1000 秒`长四倍；在其他条件不变时，曝光增加约两档。曝光档位会在快门、光圈和 ISO 都介绍之后再作整体讲解。

### 1.3 快门时间对运动的影响

快门时间决定相机记录运动的时间窗口：

- **快门时间短：** 曝光期间主体移动的距离较小，更容易凝固动作。
- **快门时间长：** 主体在曝光期间移动得更多，更容易形成拖影。

结果还与主体速度、运动方向、拍摄距离和主体在画面中的大小有关。因此，同一个快门速度不一定能让所有运动主体都清晰。

### 1.4 安全快门：降低手持抖动

**安全快门**是为降低手持拍摄时相机轻微晃动造成模糊风险而采用的经验快门速度。它针对的是**相机抖动**，不是保证移动主体清晰的速度，也不是任何情况下都绝对安全的标准。

一个常见经验是：在 35mm 全画幅相机上，手持快门时间不慢于 `1 / 焦距（毫米）`秒。例如：

- 50mm 镜头：先从约 `1/50 秒`或更快开始。
- 200mm 镜头：先从约 `1/200 秒`或更快开始。

如果在裁切画幅相机上按等效视角估算，可以把镜头焦距乘以裁切系数。例如，裁切系数约 1.5 的 APS-C 相机使用 50mm 镜头，可从约 `1/75 秒`或更快开始。这是便于理解的粗略经验，具体是否清晰还受拍摄者、设备和成片观看方式影响。

**影响安全快门的因素：**

- 手持姿势、呼吸和按快门的动作。
- 焦距和拍摄距离。长焦或近距离拍摄，细小晃动往往更明显。
- 成片的像素尺寸和观看方式。原图放大检查比缩小后观看更容易看到轻微抖动。
- 机身或镜头防抖。防抖能降低部分相机抖动风险，但不能冻结移动主体。
- 拍摄目标。是否允许轻微模糊，取决于照片用途和表达意图。

因此，`1 / 焦距`是估算起点。如果想提高成功率，可以使用更快的快门、改善手持稳定性，或把相机放在稳定支撑上。防抖效果因设备和拍摄条件而异。

### 1.5 根据拍摄对象选择快门

以下数值是帮助理解的起点，不是固定标准。实际选择还要考虑光线、拍摄距离、焦距、主体运动和希望呈现的效果。

| 拍摄对象或效果 | 可尝试的快门速度 | 说明 |
|---|---:|---|
| 静止建筑、静物，手持拍摄 | 约 `1 / 焦距`秒或更快 | 主要考虑相机抖动 |
| 日常人物、轻微动作 | `1/125–1/250 秒` | 手势或表情变化仍可能产生轻微模糊 |
| 行走的人 | 约 `1/250–1/500 秒` | 运动方向、距离会影响结果 |
| 奔跑的人、活动中的儿童 | 约 `1/500–1/1000 秒`或更快 | 动作越快，通常越需要短快门时间 |
| 快速运动或飞鸟 | 约 `1/1000 秒`起，常需要更快 | 具体取决于动作和主体在画面中的大小 |
| 拍出丝状流水 | 约 `1/4 秒`至数秒 | 较长曝光会记录水流的移动 |

在光线不足时，使用更快的快门会让照片变暗。相机的光圈和 ISO 也会影响曝光，之后会在对应主题中分别讲解。

### 1.6 手机的快门

手机专业模式里的快门时间遵循同样的基本规律：快门时间会影响曝光量和运动模糊。不过，手机可能自动进行夜景堆栈、HDR 融合或其他多帧处理，最终照片不一定来自一次单独曝光。

手机和相机的镜头、传感器和图像处理不同，因此不必直接套用相机镜头的标称焦距来计算手机的安全快门。理解快门对明暗和运动的影响，是两类设备都适用的基础。
