# 第 4 课：快门——问题与答案详解

本文件与《04-快门-时间与运动》配套。题目编号与正文一致。

## 2.1 `1/1000 秒`和`1/30 秒`，哪个曝光时间更长？

**答案：** `1/30 秒`更长。

分数的分母越小，每一份时间越长。`1/30 秒`是把一秒分成 30 份后的一份；`1/1000 秒`则是把一秒分成 1000 份后的一份。两者相比，`1/30 秒`约为`1/1000 秒`的 33 倍长。

## 2.2 为什么从`1/250 秒`改成`1/500 秒`后，照片会变暗？

**答案：** 快门时间减半，其他条件不变时，感光面接收的光量约减半，因此曝光减少一档，照片通常会变暗。

`1/250 秒`到`1/500 秒`表示曝光时间缩短了一半。这里先只看快门本身的影响；如果同时改变光圈或 ISO，最终亮度还会受那些设置影响。

## 2.3 一辆车拍得模糊，是不是一定因为快门太慢？

**答案：** 不一定。模糊可能来自主体运动、相机抖动或对焦位置不合适。

- 车在曝光期间移动，而背景清晰：更可能是主体运动模糊。
- 车和背景都沿相近方向拖动：可能是相机抖动或摇动。
- 画面中另一个位置清晰，车所在位置不清晰：可能是焦点落在别处。

所以要结合画面中哪些部分清晰、模糊呈什么方向来判断。快门能减少曝光期间记录到的运动，但不能修正对焦位置。

## 2.4 为什么拍静止建筑和拍奔跑的人，选择快门的思路不同？

**答案：** 静止建筑主要需要避免相机自身晃动；奔跑的人既要考虑相机晃动，也要考虑人物在曝光期间移动。

如果相机足够稳定，拍建筑可以使用相对较慢的快门。奔跑的人在短时间内也会移动较远，通常需要更短的曝光时间来减少人物拖影。具体需要多快，要看人物运动速度、拍摄距离和人物在画面中的大小。

## 2.5 防抖能不能让我用慢快门拍清楚奔跑的人？

**答案：** 通常不能。防抖主要帮助降低相机抖动，不能让奔跑的人停止移动。

例如，使用较慢快门拍静止建筑时，防抖可能帮助建筑保持清晰；同一快门下，奔跑的人仍可能因为自身移动而拖影。拍摄运动主体时，仍需根据动作选择足够短的快门，或者把拖影作为画面效果接受下来。

## 2.6 使用 70mm 镜头手持拍摄静止建筑，可以先试多快？

**答案：** 全画幅上可以先从约 `1/70 秒`或更快开始，例如尝试`1/80 秒`或`1/100 秒`。

这是根据“快门时间不慢于 `1 / 焦距`秒”的经验估算出来的起点，不是保证清晰的标准。手持稳定性、机身或镜头防抖、感光元件尺寸、照片放大观看的程度都会影响结果。有条件时可拍几张比较，再找到自己设备和拍摄习惯下可靠的范围。

## 2.7 快门越快，照片一定越好吗？

**答案：** 不一定。快门快适合减少运动模糊，但照片是否更好取决于拍摄目的。

如果想让飞鸟翅膀或球赛动作显得清晰，短快门通常有帮助。如果想让流水呈丝状、让车灯形成光轨，曝光期间的运动拖影正是想要的效果。快门选择是在“凝固运动”和“记录运动轨迹”之间作决定。

## 2.8 手机专业模式中的快门和相机快门是同一个概念吗？

**答案：** 基本原理相同：快门时间影响一次感光的持续时间，也影响曝光量和运动呈现。

区别在于手机可能会自动合成多帧，例如夜景模式连续拍摄并合并多张照片。此时成片可能不是由屏幕显示的一个快门时间单独决定。普通专业模式下，快门时间仍可用来理解曝光和运动效果；遇到多帧模式时，则要把计算处理一并考虑。
