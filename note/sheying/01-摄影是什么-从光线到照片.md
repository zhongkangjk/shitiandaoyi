# 第 1 课：摄影是什么——从光线到照片

## 1. 摄影不是“按下快门”，而是让光留下来

“摄影”这个词的字面意思可以理解为用光来书写。相机不是把现实场景整块复制下来，而是让场景中的光经过镜头，在感光材料上留下可保存的影像。

一张照片因此有两层身份：它是某一时刻真实光线留下的记录，同时也是摄影者从现实中截取的一小部分。摄影者决定站在哪里、何时按下快门、把什么放进画面；后续的显影、图像处理和展示也会影响观众最终看到什么。

## 2. 从现场到照片：成像的完整路径

```text
光源 → 被照亮的场景 → 反射/透射的光 → 镜头 → 感光面
                                              ↓
              ┌───────────────────────────────┴──────────────┐
              ↓                                              ↓
         数码传感器                                      胶片感光层
              ↓                                              ↓
     电信号 → 图像处理 → 文件                       潜影 → 显影/定影 → 底片
              └──────────────────┬───────────────────────────┘
                                 ↓
                         屏幕显示或打印
```

图 1：数码和胶片的成像路径。它们前半段都依靠光学成像，主要差异在于如何记录和处理影像。

### 2.1 场景本身不会主动“发出照片”

我们看到物体，是因为光源发出的光照到物体后，被反射、吸收或透过。相机记录到的通常是从物体反射出来、进入镜头的光。玻璃、水、树叶等还会透射或散射光线，所以成像不只是“物体表面反光”这么简单。

同一件物体在阳光、阴天、室内灯和霓虹灯下会呈现不同明暗与颜色，因为照到它的光变了。摄影者调整曝光可以改变记录到的亮度，但不能把没有照到物体上的光细节凭空记录出来。

### 2.2 镜头把光线组织成影像

针孔也能成像：光线沿直线穿过一个很小的孔，在对面形成上下左右颠倒的影像。但孔越小，影像越暗；孔稍大，影像又会变得模糊。镜头用经过设计的透镜组合收集更多光线，同时把来自场景各点的光尽量汇聚到感光面上，因此能在亮度和清晰度之间取得更实用的平衡。

镜头并不是“把远处物体拉近”的魔法。它决定收进画面的角度范围；摄影者移动位置会改变前景、主体和背景之间的空间关系。后面学焦距和透视时会进一步拆开这两件事。

### 2.3 感光面如何留下影像

胶片的乳剂层含有感光物质。曝光后形成肉眼暂时看不见的潜影，再经过显影、定影和冲洗，得到负片或正片。曝光和化学处理共同决定最后的影像。

数码传感器由许多感光像素组成。光子到达像素后产生电荷，读出电路把电荷转换为信号，再经处理生成图像文件。传感器本身通常并不是直接“看见红、绿、蓝三种颜色”；多数相机在像素前使用彩色滤镜阵列，处理器根据周围像素信息还原彩色图像。

```text
胶片：光 → 感光变化 → 潜影 → 化学显影 → 底片/正片
数码：光 → 像素电荷 → 电子信号 → 计算处理 → 图像文件
```

图 2：两种记录方式的简化对比。

### 2.4 数码照片也不是“传感器原样输出”

传感器记录的是一组电信号。相机需要根据白平衡、色彩配置、降噪、锐化和文件格式等进行处理，才会成为普通观看者熟悉的照片。JPEG 等格式通常已经过相机处理；RAW 文件则保存更多传感器原始数据，仍需要软件解释和调整后才能正常观看。

手机通常会做更多自动处理，例如多帧降噪、HDR 合成、局部提亮、人像虚化和锐化。于是屏幕上的成片可能是镜头成像、一次或多次曝光和算法共同产生的结果。这不代表手机“不是真摄影”，而是说明现代摄影的成像链路里，软件已经成为重要部分。

## 3. 曝光：感光面接收光的过程

**曝光**指光到达胶片或数码传感器并被记录的过程。后面会分开学习快门时间、光圈和 ISO：快门控制记录时间，光圈控制镜头的通光开口，ISO 涉及记录信号的灵敏度/增益表现。

曝光不足时，照片可能整体偏暗，阴影中的微弱信号容易被噪声淹没；曝光过多时，亮部可能达到传感器或胶片能记录的上限，细节变成一片白。明暗并非只有一个“正确值”：夜景可以保留黑暗，雪景可以很亮，剪影可以主动舍弃主体正面的细节。曝光要服从画面意图，同时了解细节何时已经无法恢复。

## 4. 相机与手机的基本组成

- **机身：** 相机的主体，容纳传感器、快门、处理器和操作机构。
- **镜头：** 收集光线并形成影像；相机镜头常可拆换，手机摄像头通常固定在机身上。
- **感光元件/图像传感器：** 数码设备中接收光并将其转换为电信号的部件。
- **取景器与显示屏：** 用来观察、构图和检查照片。单反通常通过光学取景器观察；无反相机和手机通常通过屏幕或电子取景器观察传感器画面。
- **快门按钮：** 常见相机半按可测光/对焦，完全按下拍摄；具体行为可自定义。
- **存储卡或内部存储：** 保存数码照片文件。

手机没有独立的可拆镜头、机械取景器或存储卡，并不妨碍学习摄影。先理解各部件承担什么功能，比要求手机和相机的外形一一对应更重要。

## 5. 摄影记录真实，但不等于完整事实

照片确实来自真实光线，但画面会受许多选择影响：

- **位置：** 改变拍摄点，会改变物体之间的遮挡、大小关系和透视。
- **边界：** 取景框外的内容不会出现在画面里。
- **时机：** 人物表情、动作和光线都在变化，按下快门的瞬间决定留下哪一刻。
- **曝光与对焦：** 决定哪些亮度和区域被清晰记录。
- **处理与展示：** 裁切、调色、压缩、屏幕亮度和打印都会改变观看效果。

同一个场景可以拍成旅游纪念照、新闻记录、广告图或抽象画面。相机记录光线，摄影者则通过选择让照片具有不同含义。理解这一点，后面学构图和审美时就不会把照片只看成“参数正确的文件”。

## 6. 一个小故事：早期摄影为什么需要“坐着不动”

1839 年达盖尔银版摄影术公开后不久，罗伯特·科尼利厄斯在费城给自己拍摄了一张肖像。早期银版摄影需要较长曝光，人物必须在强光下尽量保持不动；科尼利厄斯选择在自家院子里拍摄，借助自然光，并用一只歌剧望远镜的镜头改装相机。

所以那张早期“自拍”看起来不像今天的随手快照：拍摄者既是摄影师，也是模特，还得解决曝光、支撑和等待的问题。快门后来越来越快、感光材料越来越灵敏，摄影才逐渐从“摆好后保持不动”走向抓拍、街拍和体育摄影。

这个故事也提示一个重要事实：摄影史的变化并非只靠相机外观更新，而是光学、感光材料、快门、胶片、传感器和处理技术一起改变了“能拍什么”。
