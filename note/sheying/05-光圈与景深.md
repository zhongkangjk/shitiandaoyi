# 第 5 课：光圈——控制进光与清晰范围

## 1. 需要了解的知识

### 1.1 光圈是什么

光圈是镜头中控制通光开口大小的结构。光线通过镜头时，光圈开口越大，单位时间内通过的光通常越多；开口越小，通过的光通常越少。

光圈一般用 **f 值**表示，例如 `f/1.8`、`f/4`、`f/8`。理解它时要特别注意：**f 值越小，光圈开口越大；f 值越大，光圈开口越小。**

常见的完整档位序列是：

`f/1 → f/1.4 → f/2 → f/2.8 → f/4 → f/5.6 → f/8 → f/11 → f/16`

沿序列向右，光圈逐渐缩小；向左，光圈逐渐开大。不同镜头能达到的最大和最小光圈不同。

### 1.2 为什么 f 值越小，光圈反而越大

f 值是焦距与光圈有效直径的比值：

> f 值 = 焦距 ÷ 光圈有效直径

在焦距相同的情况下，光圈有效直径越大，算出来的 f 值越小。例如，同一支镜头开到 `f/2` 时的光圈，比收至 `f/8` 时大。

这个比值也解释了为什么不同焦距的镜头即使显示相同 f 值，也可以有不同的实际开口直径，但它们的单位面积曝光能力大致相同。

### 1.3 光圈对曝光的影响

在快门时间和 ISO 不变时，光圈越大，进入相机的光越多，照片通常越亮；光圈越小，进入相机的光越少，照片通常越暗。

相邻完整光圈档位的变化，通常会让进光量加倍或减半：

| 光圈变化 | 进光量变化 |
|---|---:|
| f/4 → f/2.8 | 增加 1 档，约加倍 |
| f/2.8 → f/2 | 增加 1 档，约加倍 |
| f/4 → f/5.6 | 减少 1 档，约减半 |
| f/5.6 → f/8 | 减少 1 档，约减半 |

因此，`f/2.8` 比 `f/5.6` 大两档，光圈进光量约为四倍。相机还常提供三分之一档等更细的调节。

### 1.4 光圈对景深的影响

**景深**指照片中看起来清晰的前后范围。对焦完成后，焦点所在位置最清晰；在它前后的一段范围内，影像也可能看起来足够清晰，这段范围就是景深。

在其他条件相近时：

- **光圈开大（f 值变小）**：景深通常变浅，清晰范围变窄，主体更容易从背景中分离。
- **光圈缩小（f 值变大）**：景深通常变深，前后更大范围容易显得清晰。

例如，同一位置、同一镜头和对焦距离下，`f/2` 通常比 `f/8` 更容易拍出背景虚化的人像；`f/8` 则通常能让人物前后更大范围保持清晰。

景深不是照片中“绝对清晰”和“绝对模糊”的硬边界。清晰程度会逐渐变化，最终哪些区域看起来清晰，还与照片的放大尺寸、观看距离和观察者的判断有关。

### 1.5 哪些因素会影响景深

光圈是影响景深的重要因素，但不是唯一因素。构图和对焦方式不变时，下面几项也会影响照片看起来清晰的范围。

#### 光圈

光圈开大，景深通常变浅；光圈缩小，景深通常变深。这是摄影者最直接、最常用的景深控制手段之一。

#### 拍摄距离

拍摄距离越近，景深通常越浅；距离越远，景深通常越深。因此，近距离拍摄特写，即使使用并非特别大的光圈，也可能只有很薄一层清晰。

#### 焦距与构图

在相同拍摄位置比较不同焦距时，焦距较长通常会带来更浅的景深观感。实际拍摄中，为了让主体在画面中保持同样大小，摄影者常会随着焦距改变拍摄距离，所以最终景深变化要结合距离和构图一起看，不能只凭焦距判断。

背景离主体的距离也会影响虚化观感：背景离主体越远，通常越容易显得模糊；背景贴近主体时，即使开大光圈，背景也可能仍然比较清楚。

#### 感光元件尺寸与取景范围

在取景范围相同、主体大小相同的比较中，较大的感光元件往往更容易获得浅景深效果。但如果同时改变焦距、拍摄距离或光圈，结果也会跟着改变。因此，不能只看画幅大小来判断一张照片的景深。

### 1.6 怎样根据画面需要选择光圈

选择光圈时，先考虑希望有多少范围清晰，再考虑可用光线和曝光设置：

- **希望背景虚化、突出单人主体：** 可以尝试较大光圈，同时检查眼睛等重要部位是否清晰。
- **多人合照：** 光圈不要只为虚化而开到最大；前后排人物可能不在同一清晰范围内，可适当缩小光圈或调整队形。
- **风景或建筑：** 如果希望前后细节都有较大范围清晰，可适当缩小光圈，并留意对焦位置和拍摄距离。
- **近距离特写：** 景深可能非常浅；即使光圈已经缩小，也要检查主体需要清晰的部分是否都落在景深内。
- **光线较暗：** 开大光圈可以让更多光进入镜头，但若需要较大景深，就要结合快门、ISO 或补光来处理整体曝光。

光圈同时改变曝光和景深。选定光圈后，如果照片亮度不合适，还需要结合快门和 ISO 调整；三者之间的整体配合会在后面的内容中系统讲解。

### 1.7 光圈与镜头画质的基础关系

镜头全开光圈时，有些镜头画面边缘的清晰度、暗角或像差会更明显；缩小几档后，成像表现往往有所改善。但具体表现取决于镜头设计和拍摄条件，不存在适用于所有镜头的唯一“最佳光圈”。

光圈缩得非常小时，光线会发生**衍射**，画面细节反而可能逐渐变软。日常拍摄不必因此避开小光圈；是否看得出影响，要结合感光元件、光圈、照片尺寸和用途判断。
