# 第 4 课：曝光是什么——答案详解

## 2.1 曝光指的是什么过程？

**答案：** 曝光是光到达胶片或数码传感器并被记录的过程。

曝光时长、镜头通光量和信号输出会共同影响最终照片。曝光不是单纯的后期调亮。

## 2.2 在其他条件相同的情况下，感光面接收的光增加，照片通常会怎样变化？

**答案：** 照片通常会更亮，暗部细节也更容易记录；如果光量超过感光介质可记录的范围，亮部细节可能丢失。

## 2.3 “增加一档曝光”大致表示光量发生了什么变化？

**答案：** 光量约加倍。减少一档则约为原来的一半。

一档描述的是倍数关系，不是固定增加某个亮度值。

## 2.4 曝光表显示在 0，是否表示照片一定符合拍摄者想要的明暗？

**答案：** 不一定。0 通常表示当前设置符合相机的测光建议，但相机并不知道拍摄者想保留多暗的夜景或多亮的雪地。

测光建议是参考，最终应根据主体、重要细节和画面意图判断。
